# React Custom Hooks
## Description
To understand how to fetch data in React using a custom hook `(UseFetch)` and a corresponding component `(FetchData)`. By encapsulating data-fetching logic into reusable hooks, code maintainability can be improved.

## Learning Objectives
- Master React's useState and useEffect hooks for managing state and asynchronous operations efficiently.
- Create a component named `FetchData` responsible for rendering `Fruits.json` to the UI as a list.
- Implement `useFetch` custom hooks with `url` as a dependency, encapsulates the logic for fetching data from a specified URL. This hook uses `useState` and `useEffect` to manage the data fetching process, ensuring that data is retrieved asynchronously and stored in the component's state.
- Implement `FetchYogaData` component and access the data using defined custom hook `useFetch` to render the data to UI
